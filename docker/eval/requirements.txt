# rAvI v2 evaluation image (ravi.eval: embed / metrics / seams / stats / run_eval).

# Installed with `pip install --no-deps` on top of pytorch/pytorch:2.6.0-cuda12.4-cudnn9-runtime
# (the captioner's base, same digest), which ships Python 3.11 with torch 2.6.0+cu124 and
# torchaudio 2.6.0+cu124. torch, torchaudio, torchvision and torch's own deps (triton, nvidia-*,
# sympy, mpmath, networkx) are therefore NOT listed here; the Dockerfile asserts torch/torchaudio

#
# Resolved jointly with torch==2.6.0 torchaudio==2.6.0 torchvision==0.21.0 for CPython 3.11 /
# manylinux x86_64 (2026-10-14):
#   uv pip compile <top-level pins> --python-version 3.11 \
#       --python-platform x86_64-manylinux_2_28 --exclude-newer 2025-07-01
# (--exclude-newer: the ecosystem of transformers 4.52.4; same cut as docker/captioner).
#
# Top-level pins and why:
#   laion-clap==1.1.7     latest release; CLAP_Module(enable_fusion=False, amodel='HTSAT-base')
#                         + load_ckpt() for music_audioset_epoch_15_esc_90.14.pt (README). Its
#                         metadata requires numpy<2.0.0, hence numpy 1.26.4. 1.1.7's
#                         load_state_dict() calls torch.load(..., weights_only=False) itself and
#                         drops text_branch.embeddings.position_ids for transformers >= 4.31
#                         (clap_module/factory.py), so the checkpoint needs no patching (fadtk
#                         only patches for laion_clap < 1.1.6).
#   transformers==4.52.4  MERT-v1-95M remote code imports eight classes from
#                         transformers.models.hubert.modeling_hubert, all present in 4.52.4
#                         (checked in the wheel); RobertaModel's position_ids buffer is
#                         non-persistent there, matching laion_clap's key drop. Same version as
#                         the captioner image.
#   librosa==0.11.0       beat_track(bpm=<per-frame array>), feature.tempo(aggregate=None),
#                         chroma_cqt / chroma_stft / mfcc keyword APIs used by ravi.eval.seams
#                         (checked in the 0.11.0 wheel; the dev venv runs 1.0.0, same calls).
#   scipy==1.15.3         stats.wilcoxon(x, y, zero_method, alternative, method), spatial pdist,
#                         signal.resample_poly.
#   soundfile, pandas, pyarrow   WAV I/O and the parquet/CSV outputs (same pins as docker/captioner).
#   huggingface-hub==0.33.1      hf_hub_download for the CLAP checkpoint (+ huggingface-cli).
#   pyloudnorm==0.1.1     BS.1770 integrated loudness for the -16 LUFS normalisation before CLAP
#                         (ravi.eval.embed.lufs_normalise = ravi.data.prepare_audio.normalise);
#                         0.1.1 is the last release before the cut and requires future.
# laion-clap's metadata also pulls wandb/webdataset/h5py/ftfy/... ; they are installed so its
