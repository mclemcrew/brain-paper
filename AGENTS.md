# Project design preferences

Read `PRODUCT.md` when changing the composer interface or generating review pages.
Do not use these fonts: Instrument Serif, Montserrat, Playfair Display,
DM Serif Display, Libre Baskerville, Cormorant Garamond, Public Sans,
Poppins (or “Poppin”), Lato, Space Grotesk, or Schibsted Grotesk.
This is an explicit user preference. It also applies to delegated design work.
