Listening Test — Metadata Conditioning Comparison

Companion evaluation for "Messing with Metadata: Finetuning an Open-Source Model on an Advertising Composer's Corpus"

About This Test

This page presents audio samples generated by finetuned and base (pretrained) music generation models, each conditioned on three different metadata approaches:

  • Human Captions — free-form descriptions written by music professionals
  • AI Descriptions — machine-generated captions from audio analysis
  • Industry Tags — standard genre/mood/instrumentation tags from production music metadata

For each track, the original reference is shown at the top. Compare how each metadata conditioning approach affects the finetuned model's output versus the base model.
