# Composer workspace

Recordings pairs a searchable library with the selected recording’s waveform and description. Compose places passage controls beside saved takes. Personal sound shows training controls and source excerpts; Settings contains model setup and hardware information.

The interface uses local system fonts, a light background and teal selection states. Focus indicators and reduced-motion handling remain available. The app icon is drawn in SVG: a waveform beside an outlined metadata tag. It uses no generated imagery or text fonts.

See PRODUCT.md for the design constraints. Usability and musical usefulness require separate evaluation.
