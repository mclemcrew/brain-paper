For this to be a clean test, every cell uses the same 580 training files (the earlier run silently dropped caption-less tracks from one arm), the same rvkr trigger, the same 47 s window with the structure text describing only that window, the same field-level caption augmentation, the same seeds, and excludes the duration conditioner from the adapter. Metrics are paired per section and clustered per track; distances are computed at matched clip counts against the real-audio floor; two anchors (original re-inserted, foreign section spliced in) bracket every number. Caption length still differs between arms (A 1 word, C 5, B 14, D 14, E 17) and is reported as a covariate.
